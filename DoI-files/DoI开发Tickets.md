## DOI-01 · 静态应用骨架和底栏导航

在 `public/` 建立 `index.html`、`styles.css` 和 `app.js`。使用原生 ES 模块，建立「月历」「统计」「设置」三个主视图以及返回来源页的导航能力。准备表单滚动区、提交底部区和 iPhone 安全区样式。

- [ ] Windows 本地 HTTP 服务可以打开应用，默认进入月历，底栏按「月历 · 统计 · 设置」切换。
- [ ] 窄屏下页面与底栏可正常操作，表单容器保留可滚动内容区和可见的底部按钮区域。

## DOI-02 · 本地日期与时段规则

实现 `public/dates.js`。从设备本地时间取得今天和当前时段。用 `YYYY-MM-DD` 表示发生日期，负责真实公历日期校验、月底与跨年范围、星期、连续日序和最近 365 天的边界。

- [ ] 正确识别闰日和无效日期，月份范围覆盖月初到下月月初前一日。跨时区或夏令时计算日序时，已保存的日期不会平移。
- [ ] 五个时段按 Spec 切换。核对 06:00、11:00、14:00、18:00 和午夜等边界。
- [ ] 最近 365 天含今天。本月统计截止今天，历史月份采用完整日历月。

## DOI-03 · IndexedDB 记录与设置

实现 `public/db.js`。创建 `doi` v1 的 `records`、`settings` 仓库和 `byDate` 索引。提供按 ID 或范围读取、增改删、昵称读写、备份快照及批量新增。为备份合并提供单事务入口，界面统一在事务完成后反馈。

- [ ] 新建记录以稳定 UUID 保存。同一天可以新增多条。相同 ID 的新增不能覆盖已有记录。
- [ ] 取消或失败的写事务保留原数据。编辑和删除遇到另一窗口已经修改或删除的记录，返回冲突状态供页面提示。
- [ ] 关闭再打开后，记录、空字段和昵称可正确读取。数据库版本变更和升级阻塞按 Spec 提示，旧窗口可以释放连接。

## DOI-04 · 月历与历史记录

实现月历日期网格、当天列表和独立历史页面。历史入口位于月历页。两处共用记录摘要和日期查询，向新增和详情提供选中的日期或记录 ID。

- [ ] 冷启动显示本月并选中今天。月历以周日为首列，可换月份、点日期和回到今天。有记录的日期只标一个圆点。
- [ ] 点日期后列出当天全部记录。历史页默认本月，可换月查看整月记录。发生日期和创建时间倒序，ID 提供稳定排序。
- [ ] 两处列表显示日期及已填时段和时长，空项省略。备注在详情提供。空日期和空月份有对应提示。

## DOI-05 · 新建、编辑、详情与删除

实现可滚动表单、提交状态和详情页。按入口预填日期，维护自动时段与手动选择的区别，提供 10、20、30 分钟按钮及可编辑输入，感受与备注共用多行文本框。

- [ ] 首页「＋」预填今天及当前时段。从指定日期补记时预填该日期，过去日期的时段默认留空。改成过去时清除自动选择，保留手动选择。时段可换选和取消。
- [ ] 只确认日期即可保存。时长可快捷填入、手输或清空。感受与备注保留多行，并按文本渲染。
- [ ] 内容滚动或键盘弹出时仍能提交。重复点击只新增一条，失败留在表单并保留已填内容。新增成功后选中保存日期。
- [ ] 详情显示已填信息和当前昵称。编辑日期后刷新记录归属，删除需确认并返回来源列表。两种操作都更新月历和历史。

## DOI-06 · 统计计算

在 `public/stats.js` 实现可独立复算的统计。按发生日期生成总次数、周均、去重天数、最长连续天数、固定 365 天热力图、时长样本与分段次数、星期及五个时段的分布。

- [ ] 用 Spec 固定样例核对 **4 次、3 天、周均 1.56、平均 20.0 分钟（3 条）、最长连续 3 天**，并核对 10 月 31 日及 11 月 17 日的热力图数量。
- [ ] 同日多条在次数中分别计入，在有记录天数和连续记录中按一天计算。零条数据及跨月补记结果正确。
- [ ] 平均时长仅使用有效样本，分桶边界正确。时段留空计入「未填写」，均为空时保留该数量供页面显示。

## DOI-07 · 统计页面和热力图

把统计结果接入「统计」页。提供近一年总览及指定月份切换，显示时间范围、周均、时长、连续天数、星期和时段。热力图按日期展示并链接到月历。

- [ ] 默认总览最近 365 天。切换选定月份后，统计卡片按新范围更新，热力图仍明确标注最近 365 天。
- [ ] 热力图可区分 0、1、2、3 次及以上，并能查看实际次数。点某天跳到月历并选中对应日期。
- [ ] 空状态文案准确。新建、改日期或删除后，重新打开统计即显示最新结果。

## DOI-08 · 伴侣昵称和 JSON 导出

完成设置页昵称编辑。实现 `public/backup.js` 的导出路径，读取全部记录快照，生成带格式版本的普通 UTF-8 JSON，提供系统保存及下载回退。

- [ ] 昵称可填写、修改、清空。详情显示当前昵称，昵称留空时可以正常记录。
- [ ] 文件采用 `DoI-backup-YYYY-MM-DD.json`、`format: "doi-backup"` 和 `version: 1`。记录 ID、日期、时间戳、空值和多行文字可读且完整。
- [ ] 导出内容为全部记录。iPhone 的系统保存路径在 DOI-11 验收。

## DOI-09 · JSON 导入预览和事务恢复

从系统文件选择器读取备份，校验版本、日期和所有记录字段，按 ID 预览新增与跳过数量。确认后在一个读写事务中重新检查并新增缺少的 ID。

- [ ] 空环境恢复后，记录及统计与导出时一致。重复导入新增 0 条。文件内同 ID 取首条，和本机同 ID 时保留本机版本。
- [ ] 用户取消、格式不支持、记录字段错误、文件损坏或写入失败时，原记录保持完整。
- [ ] 预览后本机数据变化时，确认阶段以实际事务结果为准。导入完成后更新月历、历史和统计。

## DOI-10 · 主屏幕安装、离线及更新

实现固定应用 ID 的 Manifest、图标和 `apple-touch-icon`。用版本化 Service Worker 预缓存完整的静态应用。预缓存就绪后显示离线可用。

- [ ] 缓存包含全部页面骨架、样式、模块、Manifest 和图标，断网可启动各页面。静态资源和 IndexedDB 分别管理。
- [ ] 新 Worker 完整缓存成功后等待旧页面关闭再激活。缓存失败时继续使用现有版本。旧缓存清理只针对 DoI。
- [ ] 在 HTTPS 上切换两个发布版本，关闭重开后能启用新版，旧记录仍可读取，编辑中的页面不被强制刷新。

## DOI-11 · iPhone 真机验收和发布

用虚构数据在 iPhone 从 Safari 添加到主屏幕。按 [需求文档的验收清单](./DoI需求文档.md#6-v1-真机验收) 逐项记录结果。正式发布使用固定的 HTTPS 生产网址，上传 `public/`。

- [ ] 主屏幕打开直达月历。首次缓存后开飞行模式，退出重开仍能新增、编辑、查看、统计及导出。
- [ ] iPhone 键盘打开时可以保存表单。切换月份、详情返回和热力图跳转符合预期。
- [ ] 离线保存备份至「文件」，在空测试环境恢复并核对记录。重复导入及无效文件符合预期。
- [ ] 在同一网址验证新版、旧数据与再次离线启动。记录受测 iOS 版本、测试结果及仍待解决的问题。
