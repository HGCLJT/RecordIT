# DoI 产品需求文档

**版本** V1.0 需求草案  
**使用场景** 个人在 iPhone 上记录与伴侣的亲密经历，日后按日期回看。

## 1. 目标和发布范围

| 阶段 | 功能范围 |
| --- | --- |
| V1 个人记录 | 主屏幕安装、离线记录、月历、历史筛选、统计、隐私显示、JSON 备份与恢复 |
| V1 后续扩展 | 手动添加到 Apple 日历、更多可选记录项 |
| V2 双人记录 | 先验收 iPhone 主屏幕 PWA。支持双方配对、整条记录共享、选择旧记录同步、离线后同步和冲突处理。安卓适配后续验收。 |
| 共享相册 | 配对后任一方可上传图片或视频，双方都可查看。 |
| 待评估 | 周期记录和 Apple Watch |

V1 只记录情侣共同的亲密经历，由一个人录入和管理。伴侣昵称选填，在设置里统一填写和修改。记录详情显示当前设置的昵称，昵称留空时可正常新增和查看记录。安装和更新采用 iPhone 主屏幕 PWA 方式，无需 Apple 开发者会员或定期续签。配套部署步骤见 [PWA 开发方案](./PWA开发方案.md)。

## 2. 页面和使用流程

底栏主导航从左到右为「月历」「统计」「相册」「设置」。在月历页点「历史记录」进入独立的历史列表。

| 页面 | 功能 |
| --- | --- |
| 月历（首页） | 点主屏幕上的 DoI 图标直接进入月历，默认显示本月。支持切换月份、回到今天和选择日期。有记录的日期显示一个圆点。点某天后在月历下方列出当天记录，可补记或进入详情。首页提供「＋」和独立的「历史记录」入口。点「＋」打开新增表单。 |
| 新增／编辑 | 新增和编辑使用可纵向滚动的表单，底部固定提交按钮。新增时显示「新建记录」，编辑时显示「保存修改」。打开后直接显示填写项。首页新增预填今天，从某日的列表新增时预填所选日期。日期确认后即可提交，选填内容可以日后补上。 |
| 记录详情 | 查看已填内容及设置中的伴侣昵称，支持编辑和删除。删除前确认，成功后更新当天列表、月历和统计。 |
| 历史记录 | 独立页面，默认展示本月，支持切换月份。整个月的记录按发生日期从新到旧排列，同一天的多条记录分别显示，点任一条进入详情。当天列表和历史列表都展示记录日期，以及已填写的时段和时长，例如「晚上 · 20 分钟」。 |
| 统计 | 显示次数、周均、有记录的天数和近一年热力图，提供时长、连续记录、星期和时段统计。 |
| 相册 | 联网后上传图片或视频、预览图片及播放视频。上传者可以从共享相册删除文件。 |
| 设置 | 编辑伴侣昵称、导出 JSON 备份和恢复。 |

**日常记录**　打开 DoI → 点「＋」→ 在表单核对日期或填写详情 → 点底部「新建记录」。  
**补记**　月历选日期 → 新增 → 确认预填日期、按需填详情 → 点「新建记录」。  
**回看**　月历选日期，在下方看当天记录。需要浏览整月时，从首页进入「历史记录」，选择月份后点一条记录查看详情。

### 统计口径

| 指标 | 第一版规则 |
| --- | --- |
| 时间范围 | 总览默认最近 365 个日历日，含今天，可切换到指定月份。当前月份计算到今天，历史月份计算整月。各指标注明所属范围。 |
| 次数、周均、有记录的天数 | 次数按条计算，天数按发生日期去重。同一天两条显示「2 次 · 1 天」。周均按所选期间的记录数除以该期间的天数再乘 7，保留两位小数。 |
| 近一年热力图 | 固定显示最近 365 天，明确标注范围。颜色按每个日期的记录条数区分，点击日期可查看当天记录。 |
| 时长 | 显示平均时长和分段次数，只计算填写了时长的记录，并标注样本数。 |
| 连续记录 | 显示所选范围内最长连续有记录的天数，同一天多条只算一天。 |
| 星期和时段 | 星期按发生日期统计，时段按表单里的五个按钮统计。显示每个类别的次数，时段留空的记录单列为「未填写」。 |

无样本的时长或时段卡片提示暂无数据。评分、共同／Solo 比例、高光和健康数据等参考图中的指标，分别对应其他记录字段或数据来源，后续有相关需求时再讨论。

## 3. 记录字段和规则

| 字段 | 第一版规则 |
| --- | --- |
| 发生日期 | 必填，按用户选定的日历日期保存，用于列表、月历和统计。记录已发生的经历，日期可选今天或过去。 |
| 发生时段 | 选填，提供「凌晨」「上午」「中午」「下午」「晚上」五个按钮。新增今天的记录时按 iPhone 当前本地时间预选。可换选，再点选中项可取消。补记过去日期时默认留空。 |
| 时长 | 选填，按分钟记录。提供 10、20、30 分钟快捷选项，也可手动输入分钟数。快捷选项填入同一个输入框，填入后可修改或清空。 |
| 感受与备注 | 选填，使用同一个多行文字栏记录当时的感受或其他细节。保存后可编辑。 |

- 每次经历一条记录。同一天可以保存多条，重复点同一次提交只产生一条。
- 时段预选规则为凌晨 00:00–05:59、上午 06:00–10:59、中午 11:00–13:59、下午 14:00–17:59、晚上 18:00–23:59。若把日期改成过去，清除自动预选的时段。手动选择的时段保留。编辑已有记录时显示已保存的时段。
- 每条记录保留稳定的唯一 ID、创建时间和修改时间。补记按发生日期归类。比如 11 月录入 10 月 31 日发生的记录，计入 10 月。
- V1 使用以上常用字段。姿势、射精位置等细项列入后续扩展需求。

## 4. 数据、离线和隐私

- **本机存储**　记录和设置保存在 iPhone 主屏幕 App 的 IndexedDB。PWA 托管只提供网页文件。页面通过统一的数据读写接口访问本机数据库，为未来同步预留迁移路径。
- **离线使用**　首次从主屏幕联网打开并完成缓存后，断网可新增、补记、编辑、删除、筛选、看统计和备份。保存成功以本机数据库写入完成为准。
- **隐私显示**　月历上有记录的日期用圆点标记。记录列表显示日期及已填写的时段和时长。「感受与备注」进入详情后显示。统计页可主动打开查看数值。
- **导出**　导出带格式版本的普通 JSON 文件，存到 iPhone 的「文件」。文件中可直接读取全部记录。
- **恢复**　选择 JSON 文件后校验格式并预览将新增和跳过的数量。按稳定 ID 合并，重复记录保留本机已有版本。文件格式不支持、文件损坏或写入失败时，已有数据保持完整。换机后可以用同一个备份恢复。
- **更新**　使用同一生产网址发布新版，继续通过原主屏幕图标打开。升级后仍能读取旧记录，需要变更字段时迁移本机数据库。

## 5. 后续需求

- **Apple 日历**　从单条记录手动触发快捷指令，把选定日期写入用户选择的日历。默认用中性标题「纪念」，「感受与备注」留在 DoI。写入的是独立事件，之后在两处分别编辑或删除。
- **双人共享**　双方先配对。保存一条共享记录时，日期、时段、时长和「感受与备注」作为整条记录同步，对双方可见。已有单机记录默认留在原设备，由记录持有人选择要共享的旧记录。选中的旧记录同样按整条同步。双方都能新增，发布者可以编辑和删除自己发布的共享记录。两台设备同时添加会各自产生一条，网络重试会按同一次操作去重。同步冲突保留本机修改供处理。解除配对会关闭原共享空间的联机访问，用户可提前导出要保留的共享记录。

## 6. 共享相册

- 配对成员可以上传图片和视频，打开或刷新相册即可查看另一方上传的内容。上传表单会说明两位成员都可查看。
- 文件保存在私有 Backblaze B2 存储桶中。列表、预览、播放和删除都通过情侣空间会话鉴权。解除配对后，两位成员都失去访问权限。
- 图片单个最多 10 MB，视频单个最多 500 MB。超过 50 MB 的视频分片上传，在同一个上传窗口中可以暂停并继续。播放和预览取决于设备对编码格式的支持。
- 相册文件的保存独立于记录的 JSON 备份。使用设备恢复码登录另一台设备后，可访问原情侣空间的相册。

## 7. V1 真机验收

- [ ] 从 Safari 添加到主屏幕，点 DoI 图标直接进入月历。联网完成首次缓存后，开启飞行模式，关闭并重新打开 App，仍能新增和查看记录。
- [ ] 首页点「＋」打开表单，预填今天。滚动时底部「新建记录」按钮始终可用，提交后才新增一条记录。
- [ ] 首次使用时，只填日期即可保存一条情侣记录。从月历选上月某天补记时，表单预填该日期，保存后计入上月。同一天新增两条显示「2 次 · 1 天」。
- [ ] 编辑记录日期或删除记录后，月历、当天列表、统计和热力图都准确更新。
- [ ] 用同日多条、跨月、连续日期和缺少时长或时段的记录核对统计。总览可在近一年和指定月份间切换，周均、有效样本的平均时长、最长连续天数和各时段次数符合统计口径。
- [ ] 新增今天的记录时，自动选中当前本地时间对应的时段。可换选、取消并保存。从过去的日期补记时，时段默认留空。把日期改为过去时清除自动预选，手动选择保留。
- [ ] 时长可留空。可用快捷选项填入分钟数，手动调整后保存，详情显示调整后的时长。
- [ ] 可在设置中填写、修改或清空伴侣昵称。记录详情显示当前昵称，昵称留空时也能新增和查看记录。
- [ ] 底栏可切换月历、统计和设置。点月历日期可在下方查看当天记录。从月历页进入历史记录，可按发生日期倒序浏览整个月、切换月份并打开任一条记录的详情。点热力图能打开对应日期的记录。
- [ ] 同一天保存多条记录时，月历仍显示一个圆点，点日期可查看当天全部记录。当天列表和历史列表中，已填写的时段和时长可直接查看，空白项不占位。「感受与备注」使用同一个文字栏，支持输入、保存和编辑多行文字，在打开详情后才显示。
- [ ] 在 iPhone 上离线导出普通 JSON 备份并保存到「文件」，再导入空的测试环境。核对恢复后的记录。恢复前可预览新增和跳过数量。重复导入无重复，格式不支持或文件损坏时不影响已有数据。
- [ ] 同一网址发布新版，从原主屏幕图标打开并完成更新。旧记录仍在，更新后再次断网可用。
